# Maati Katha

Research, visual material, and a static website prototype for **Maati Katha: The Weight of Belonging**.

The current website lives at:

```text
maati-katha-research/index.html
```

It can be opened directly in a browser. The website assets live in:

```text
maati-katha-research/assets/
```

The wider research folder includes spatial notes, brand identity, truth-audit notes, Earth Studio planning, source village photos, and video material.
