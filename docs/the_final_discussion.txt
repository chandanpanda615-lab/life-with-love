     Photographic hero for Maati Katha

     Context

     The homepage hero (index.html 871–903) is currently text-on-canvas: a
     procedurally
     drawn landscape (<canvas id="scene">) behind a left-aligned wordmark, two
     buttons,
     and a 4-column status ledger. It works, but it is dense and illustrated.

     The user supplied four reference designs (Kauai/Saturdays NYC, a
     golden-hour resort
     photo, and two CarmoWood screens). Taken as reference, not conclusion, they
     share:

     - a full-bleed photograph with a dark scrim, not an illustration
     - a centred, very sparse typographic lockup — small uppercase kicker, large
     serif
     wordmark, one short line of lede
     - an explicit scroll cue at the bottom centre
     - a warm earth palette, and a cream/dark-brown panel immediately after the
     photo

     The site's existing tokens (--laterite, --turmeric, --ash, Cormorant
     Garamond)
     already match that palette, so this is a layout and asset change, not a
     rebrand.

     Outcome: a photographic hero that shows the real place, with the honest
     project status preserved — moved to a cream band directly below rather than
     deleted.

     Constraint discovered during exploration

     There is no usable hero photograph in the repo. Village_Image/ is empty
     (all
     files deleted, unstaged). The only real imagery is
     maati-katha-research/assets/, and
     fields-road.jpg, hills-mist.jpg, house-road.jpg are each a 6-photo collage,
     not a single image. satellite.jpg / earth-*.jpg are dry-season Google Earth
     frames
     with a visible watermark.

     So the hero photo must be cropped out of a collage panel. Gutters were
     measured:
     fields-road.jpg (1500×1500) has white gutters at cols/rows 0–28, 983–1003,
     1471–1499,
     making the top-left panel exactly (29, 29, 983, 983) — misty hill, green
     paddy,
     red dirt road.

     assets/hero.jpg — the hook exists, the file does not).

     One-off crop with PIL 12.2.0 (already installed). Run from the scratchpad;
     do not
     commit the script:

     from PIL import Image
     im = Image.open("maati-katha-research/assets/fields-road.jpg")
     im.crop((29, 29, 983, 745)).save("assets/hero.jpg", quality=82,
