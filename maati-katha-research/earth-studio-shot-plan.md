# Maati Katha — Google Earth Studio Shot Plan

*Created: 5 May 2026.*

Use Google Earth Studio's **Quick Start → Point-to-Point** or **Quick Start → Zoom-To** feature to create a short spatial opening for the website. The goal is not a flashy travel video. The goal is to show the viewer that Sarangada is a real place inside a larger terrain system.

## Recommended Feature

Use **Quick Start → Point-to-Point** for the main website animation.

Why:
- It can move from a wider Kandhamal view into Sarangada.
- It supports the "from map to ground" idea already added to the website.
- It is more useful than a pure orbit because the project is about arrival and orientation, not spectacle.

Use **Quick Start → Orbit** only for a short secondary clip around the village point or western hills.

## Shot 1 — Region To Village

Purpose: show how remote Sarangada is before naming the stay.

Suggested structure:

| Keyframe | View | Notes |
|---|---|---|
| 1 | High view over Odisha / Eastern Ghats | Slow, quiet opening. |
| 2 | Kandhamal district area | Let forest and road distance become visible. |
| 3 | K. Nuagaon / Sarangada area | Begin the descent. |
| 4 | Sarangada village point | End above the village, not too close. |

Suggested duration: 10-14 seconds.

Camera feel:
- Smooth descent
- No fast spinning
- Mild tilt only near the end
- End with enough altitude to read village, fields, and hills together

## Shot 2 — East To West Logic

Purpose: show the central brand idea: the day flows west.

Use either Point-to-Point or manual keyframes.

Suggested structure:

| Keyframe | View | Notes |
|---|---|---|
| 1 | Eastern / northern fields | Start over cultivated side. |
| 2 | Market spine | Move across the village core. |
| 3 | Western hills | End toward the forest side. |

Suggested duration: 7-9 seconds.

Camera feel:
- Lower altitude than Shot 1
- Almost no rotation
- Let the east-to-west movement carry the idea

## Shot 3 — Gentle Orbit Around The Village

Purpose: optional background loop for a section, not the hero.

Use **Quick Start → Orbit**.

Suggested structure:
- Center point: Sarangada village core
- Radius: wide enough to include fields and western hills
- Duration: 8-10 seconds
- Angle: shallow, not dramatic

Avoid:
- Aggressive 3D tilt
- Fast rotation
- Heroic trailer feeling

## Export Settings

For website use:

| Setting | Recommendation |
|---|---|
| Resolution | 1920 × 1080 |
| FPS | 24 or 30 |
| Format | Image sequence if editing later, MP4 if direct |
| Duration | 8-14 seconds per shot |
| Use on site | Compress to `.mp4` and create a poster `.jpg` |
