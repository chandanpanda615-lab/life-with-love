# Maati Katha — Research Project README

*Last updated: 5 May 2026.*

This is the working research folder for *Maati Katha: The Weight of Belonging* — a seven-day life-exchange project in Sarangada, Kandhamal, Odisha.

Current operating posture: **research and invitation-only pilot planning**. Do not treat the public website language as a launch promise until the truth audit, fieldwork consent, host model, safety plan, and first private pilot are complete.

The research is organized into five layers (Visual, Land, History, Living Culture, Radius) plus a Content folder for brand-ready writing and a master brand identity file at the root.

## How to use this folder

### When you're researching

Work inside the matching numbered folder. Create `notes.md` inside each layer's folder for working notes. When a layer is closed at first-pass depth, create a `layer-N-final.md` that summarizes the findings (Layer 1 is an example).

### When you're writing brand copy

Start with `truth-audit.md`. Only publish claims marked `TRUE`, and use claims marked `LIKELY` only when they are phrased cautiously. Pull material from `04-content/observation-pool.md` (raw sentences) and rework into your voice. Save new drafts in `04-content/` with version numbers (`journal-drafts-v2.md`, etc.).

### When you're making brand decisions

`brand-identity-master.md` is the source of truth. Update it whenever a decision changes. The "Locked decisions log" at the bottom of that file shows what is settled and what is still open.

### When you're in Sarangada doing fieldwork

Update `notes.md` in the relevant layer folder. Photos from a visit go in `01-visual/bhuvan-screenshots/` or a new `01-visual/field-photos-DATE/` folder. Always single-subject photos, never collages.

## File-naming conventions

- Use lowercase and hyphens: `layer-1-sarangada-spatial-final.md`
- Date when relevant: `field-photos-2026-06-15/`
- Version when iterating: `journal-drafts-v2.md`
- Final / locked versions: append `-final` only when truly closed
- Avoid spaces in filenames
